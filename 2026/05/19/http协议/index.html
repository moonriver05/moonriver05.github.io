http协议

http简介

http是Hyper Text Transfer Protocol（超文本传输协议）的缩写。主要适用于从www服务器到本地服务器通过请求-响应方式的超文本传送。http是一种应用层协议，通过TCP（或TLS）进行发送，用户在本地客户端浏览器对特定域名进行访问或者是上传资源。服务器会通过http协议（请求头，请求体，响应头，响应体）进行传输文本。客户端浏览器可以解析html等其他文件，按照特定的格式展示给用户。

http基本原理

http协议规定了客户端和服务器之间的传输格式。采用请求和响应的方式，每个方式里面又分为头和体。响应里面的内容包括了，响应状态，响应内容，服务器信息等内容。

1.客户与服务器进行连接。

这个客户端的一般形式就是浏览器。它与服务器的http端口进行连接。

2.客户向服务器发送请求

通过tcp建立连接，客户端向服务器发送一个请求报文，一般格式就是

(1).请求行（请求方法，请求URL，http版本）

(2).请求头（host服务器域名端口，user-agent客户端类型，accept接受类型之类的）多个键值对

(3).空行（)

(4).请求体（一般只有post，put等需要提交数据的请求，携带客户端向服务器发布的数据）

3.服务器接受请求，并根据请求返回响应文件

服务器解析用户请求，同时申请资源，将资源副本写入tcp，交给客户端进行读取。

以响应的格式返回，格式和请求体基本一致。

(1).状态行 (请求是否成功，或者出了什么错误)

(2).响应头（描述响应的数据，说明格式是什么，响应体长度，保存cookie，如何缓存）

(3).空格 （)

(4).响应体 （实际返回的业务数据）

4.客户与服务器关闭连接

如果客户主动关闭链接则connection为close，则响应后会主动断开tcp，如果服务器配置了keep-alive超时时间，或者最大请求数

则在处理完最后一个是响应的时候，主动断开链接。或者是某一方的崩溃，通过tcp的检测对方无响应则关闭。

5.客户端解析返回的文件内容

客户端浏览器会解析状态行，判断是否成功，然后再解析每一个响应头，读取里面的响应体的内容再以特定的比方说html的格式

进行内容展示。

http的状态码

状态码是显示请求响应状态的东西。下面将展示一些常用的http状态码

1.成功类（2xx)——一切正常

状态码 含义 典型场景
200 OK get请求成功返回数据，put更新成功
201 Created post创建新用户、新订单成功
204 No Content 删除操作成功，保存设置成功

2.重定向类(3xx)——需要额外操作

状态码 含义 典型场景
301 Moved Permanently 网站域名永久更换（http:// –>https://)
302 Found 临时跳转（未登录用户跳转到登录页）
304 Not Modified 使用本地缓存（浏览器第二次请求同一张图片时）

3.客户端错误类（4xx)——请求有问题

状态码 含义 典型场景
400 Bad Request 请求参数格式错误（比方说json语法错），缺少必要字段
401 Unauthorized 未登录或者登陆过期
403 Forbidden 已经登陆但是权限不足
404 Not Found 请求的URL不存在
405 Method Not Allowed 对某些接口使用了错误的http方法，比方说只支持post但是你使用了get
429 Too Many Requests 超出了API限流（一秒钟请求了太多次）

4.服务器错误类（5xx）——服务器出问题

状态码 含义 典型场景
500 Internal Server Error 后端代码抛出异常 (空指针、数据库连接失败未处理)
500 Bad Gateway 网关/代理后方的服务挂了 (如 Nginx 后面的 PHP-FPM 崩溃)
503 Service Unavailable 服务器过载、正在停机维护
504 Gateway Timeout 网关等待上游服务响应超时 (如后端处理耗时超过 30 秒)

http Cookie

cookie的一般信息。

1.存储信息，cookie一般会在浏览器里面保存一小段文本信息（不一定是账户密码，也可以是个性化推荐，深色模式或者跟踪分析之类的）。

2.域名绑定：cookie会绑定到具体的域名，浏览器只会把cookie发给这个域名，不会发送给别的网站。

3.自动放在header，每次请求改页面的时候，浏览器就会自动从硬盘里面读取对应的cookie，塞到http请求头的cookie字段里面这样就是记住登录，以后访问同一个域名的时候就不需要再次登陆了。

但是cookie也有过期时间：一般会话cookie：不设置过期时间，浏览器一关就删掉（登陆状态通常用这种）

​ 持久cookie：设置了expires或者max-age，会保存到硬盘上，关闭浏览器打开还在（比方说“记住我”）
